# NILM document vault

Open this directory as an Obsidian vault. It holds traceable reading notes and research synthesis for NILM loss benchmarking.

Suggested organization:

- `inbox/` — unprocessed papers and capture notes.
- `papers/` — one note per paper, with bibliographic details, evidence, methods, results, limitations, and citation location.
- `synthesis/` — cross-paper comparisons, open questions, and candidate claims.
- `assets/` — figures or local attachments referenced by notes.

Create these folders only when they receive content. Keep source links, page/section references, and any uncertainty in each paper note so later claims can be checked.
