# NILM loss benchmark

Workspace for literature evidence, reproducible experiments, and the eventual paper.

## Workflow

1. Add and synthesize research evidence in [`nilm-document/`](nilm-document/README.md), using Obsidian.
2. Develop and run experiments in [`nilm-code/`](nilm-code/README.md).
3. Begin the manuscript in [`nilm-paper/`](nilm-paper/README.md) only after the literature record and experimental results support its claims.
